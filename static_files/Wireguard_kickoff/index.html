The Lean FRO

The nonprofit behind the Lean programming language and proof assistant.

Launched in July 2023 by Leo de Moura and Sebastian Ullrich under Convergent Research.

  • Mission: make formal verification accessible across mathematics, software and hardware verification, and AI-assisted theorem proving.

  • Focus: scalability, usability, proof automation, documentation — and guiding Lean toward long-term self-sustainability.

  • 20 engineers. Open source. Controlled by no single company. Many team members recruited from the Lean community.

  • 32 releases and 9,000+ pull requests merged since launch.

  • Supported by philanthropic donations: Alex Gerko, Alfred P. Sloan Foundation, Amazon, Richard Merkin Foundation, Simons Foundation.

Industrial users: Amazon, Google, Meta, and Microsoft.

AI Startups

  • Axiom: solved 12/12 problems on Putnam 2025.

  • DeepSeek Prover-V2: 88.9% on miniF2F. Open-source, 671B parameters.

  • Harmonic: built the Aristotle AI — gold medal, IMO 2025.

Current Work: Mathematics

  • Lean Eval — public leaderboard of AI formalization results on a benchmark of hard Lean problems.

  • Tau Ceti — AI-authored Lean mathematics: humans own the roadmap, AIs write and review the code, and progress is gated by open, adversarial review.

  • Verso — type-checked documents: papers, lecture notes, slides, and websites in one tool. Every Lean example is checked. lean-lang.org is written in Verso.

  • Lean Workbench (coming soon) — zero installation: manage Lean and Verso Blueprint projects in the browser, pre-configured with AI. Built for teaching.

Current Work: Software Verification

  • grind — SMT-inspired proof automation, native to dependent type theory. Congruence closure, E-matching, and theory solvers. Produces kernel-checkable Lean proofs. 5,000+ uses in Mathlib.

  • SymM — new monadic framework for high-performance symbolic verification. Built for tools that must discharge thousands of verification conditions efficiently.

  • vcgen — Lean's verification-condition generator for monadic programs. Ported to SymM: tactic and kernel time now scale linearly with goal size.

  • Iris Lean (external) — port of the Iris higher-order concurrent separation logic framework from Rocq to Lean.

These pieces come together in Signal Shot: verifying the Signal protocol and its Rust implementation in Lean.

SymM: Scalable Symbolic Verification

  • SymM: new monadic framework for high-performance software verification. Born after the Lean@Google Hackathon.

  • Designed for tools like Aeneas, vcgen, and Velvet that need to discharge thousands of verification conditions efficiently.

Without this, verifying something as large as Signal is slow and painful. With it, verification conditions get discharged efficiently.

Iris Lean

Iris is a higher-order concurrent separation logic framework implemented in Rocq.

Very popular. 150+ papers since 2015.

Iris Lean is a port of Iris to Lean. Progress (last week): 70.3%

Started as Lars König's master's thesis (2022). Maintained by Mario Carneiro until 2025; then Markus de Medeiros and many others got interested.
